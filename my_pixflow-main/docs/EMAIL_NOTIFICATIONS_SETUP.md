# راه‌اندازی ایمیل خودکار برای پیام‌ها و سفارش‌های جدید

با این تنظیم، هر وقت کسی فرم Contact یا Order رو پر کنه، یک ایمیل فوری بهت می‌رسه — بدون نیاز به چک کردن مداوم پنل ادمین.

از سرویس **Resend** استفاده می‌کنیم: رایگان (۱۰۰ ایمیل در روز، ۳۰۰۰ در ماه)، بدون کارت بانکی، بدون نیاز به تنظیم دامنه‌ی اختصاصی (از یک آدرس تستی پیش‌فرض استفاده می‌کنه).

---

## مرحله ۱ — ساخت اکانت
1. برو به [resend.com](https://resend.com) → ثبت‌نام رایگان (با ایمیل یا گیت‌هاب).
2. بعد از ورود، از منوی سمت چپ روی **API Keys** کلیک کن.

## مرحله ۲ — ساخت کلید
1. **Create API Key** بزن.
2. یک اسم بذار (مثلاً `pixflow-notifications`).
3. Permission رو روی **Sending access** بذار (نیازی به Full access نیست).
4. کلید ساخته‌شده رو کپی کن — فقط یک‌بار نشون داده می‌شه.

## مرحله ۳ — تنظیم روی Render
برو به Render → سرویس `my_pixflow` → **Environment** → این متغیر رو اضافه کن:

| Key | Value |
|---|---|
| `RESEND_API_KEY` | کلیدی که از مرحله ۲ گرفتی |

(نیازی به `NOTIFY_EMAIL` جداگانه نیست — پیش‌فرض همون `ADMIN_EMAIL` که از قبل داری استفاده می‌شه. اگه می‌خوای ایمیل جدا از ایمیل ادمین باشه، `NOTIFY_EMAIL` رو هم جدا اضافه کن.)

## مرحله ۴ — تست
بعد از Redeploy، از سایتت یک پیام تستی از فرم `/contact` یا `/order` بفرست. باید ظرف چند ثانیه یک ایمیل با موضوع «New message: ...» به ایمیلت برسه.

---

## نکات مهم
- **فرستنده‌ی ایمیل** فعلاً `onboarding@resend.dev` هست (آدرس تستی رسمی Resend) — این کاملاً کار می‌کنه ولی ممکنه گاهی وارد پوشه‌ی اسپم بشه. اگه بعداً دامنه‌ی اختصاصی (`pixflow.agency` یا مشابه) خریدی، می‌تونیم فرستنده رو به آدرس خودت (مثلاً `notifications@pixflow.agency`) تغییر بدیم که حرفه‌ای‌تر و قابل‌اعتمادتره.
- دکمه‌ی **Reply** روی این ایمیل‌ها مستقیم به ایمیل فرستنده‌ی پیام (مشتری) می‌ره، نه به Resend — یعنی می‌تونی مستقیم از inbox خودت جواب بدی.
- اگه `RESEND_API_KEY` تنظیم نشه، هیچ مشکلی برای سایت پیش نمیاد — فقط ایمیل نمی‌رسه، پیام‌ها هنوز عادی توی پنل ادمین ذخیره می‌شن.
