# راه‌اندازی چت‌بات هوش مصنوعی

با این تنظیم، یک ویجت چت شناور (پایین-چپ سایت، کنار دکمه‌ی واتس‌اپ) به همه‌ی صفحات اضافه می‌شه که به سؤالات پایه‌ای بازدیدکننده‌ها (قیمت‌ها، خدمات، نحوه‌ی سفارش) خودکار و دقیق جواب می‌ده.

از **Google Gemini API** استفاده می‌کنیم: رایگان، بدون کارت بانکی، سهمیه‌ی روزانه‌ی سخاوتمندانه.

---

## مرحله ۱ — گرفتن کلید API
1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. با اکانت گوگلت وارد شو.
3. روی **Create API Key** بزن.
4. یک پروژه‌ی گوگل انتخاب کن (یا بذار خودش یکی بسازه).
5. کلید ساخته‌شده (شروع می‌شه با `AIza...`) رو کپی کن.

## مرحله ۲ — تنظیم روی Render
برو Render → سرویس `my_pixflow` → **Environment** → این متغیر رو اضافه کن:

| Key | Value |
|---|---|
| `GEMINI_API_KEY` | کلیدی که از مرحله ۱ گرفتی |

## مرحله ۳ — تست
بعد از Redeploy، سایتت رو باز کن. یک دکمه‌ی گرد مشکی پایین سمت چپ صفحه باید ظاهر بشه (کنار دکمه‌ی سبز واتس‌اپ). روش کلیک کن و یک سؤال تستی بپرس، مثلاً:
- «قیمت پکیج Professional چقدره؟»
- «چطور می‌تونم سفارش بدم؟»

باید جواب دقیق و مبتنی بر اطلاعات واقعی سایتت (نه حدسی) بگیری.

---

## نکات مهم

### اگه کلید رو تنظیم نکنی چی می‌شه؟
هیچ مشکلی برای سایت پیش نمیاد. ویجت چت هنوز نمایش داده می‌شه، ولی به هر پیامی با یک جواب مودبانه («لطفاً از فرم تماس استفاده کنید») پاسخ می‌ده تا وقتی کلید رو اضافه کنی.

### چت‌بات از کجا اطلاعاتش رو می‌گیره؟
اطلاعات (قیمت‌ها، پکیج‌ها، خدمات، FAQ) مستقیماً داخل کد (`chat.js`) نوشته شده — یعنی هیچ‌وقت چیزی رو حدس نمی‌زنه یا اختراع نمی‌کنه. اگه بعداً قیمت‌ها یا پکیج‌ها روی `pricing.html` عوض بشن، باید همون اطلاعات رو دستی توی `chat.js` (بخش `SYSTEM_PROMPT`) هم به‌روزرسانی کنی، وگرنه چت‌بات اطلاعات قدیمی می‌ده.

### ⚠️ مدل‌های Gemini منقضی می‌شن — یه چیزی که باید مراقبش باشی
گوگل هر چند وقت یک‌بار مدل‌های قدیمی رو کاملاً خاموش می‌کنه (مثلاً `gemini-2.0-flash` در ۱ ژوئن ۲۰۲۶ رسماً Retire شد). وقتی این اتفاق بیفته، **سایت crash نمی‌کنه** (چون Fail-Safe طراحی شده)، ولی چت‌بات فقط پیام «موقتاً در دسترس نیستم» می‌ده — بدون هیچ خطای واضحی که خودت متوجه بشی.

اگه یه روز چت‌بات دوباره همیشه همین پیام رو داد:
1. برو Render → Logs، دنبال خط `Chat reply failed: Gemini API error 404` بگرد — گوگل معمولاً **مستقیم داخل همون پیام خطا** می‌گه کدوم مدل رو جایگزین کنی (مثلاً «Please update your code to use models/gemini-X.X-flash»).
2. یا برو [ai.google.dev/gemini-api/docs/pricing](https://ai.google.dev/gemini-api/docs/pricing) و ببین کدوم مدل الان فعاله.
3. توی فایل `pixflow-server/chat.js`، خط `const MODEL = '...'` رو با اسم مدل جدید عوض کن.
4. Commit و Push کن.

### محدودیت مصرف
برای جلوگیری از سوءاستفاده، هر بازدیدکننده (بر اساس IP) حداکثر ۲۰ پیام در هر ۱۵ دقیقه می‌تونه بفرسته. این هم از هزینه (که صفره چون رایگانه) جلوگیری نمی‌کنه، بلکه فقط از تمام شدن سهمیه‌ی روزانه‌ی رایگان توسط یک نفر جلوگیری می‌کنه.

### امنیت
چت‌بات فقط درباره‌ی خدمات Pixflow جواب می‌ده (طبق دستورالعمل داخلی‌اش) و هیچ‌وقت قیمت نهایی قطعی اعلام نمی‌کنه — همیشه به مشاوره‌ی رایگان و فرم سفارش ارجاع می‌ده.
