# Pixflow — بریف سفارش‌گیری مشتری و ساختار پروژه

سند مرجع داخلی برای فرایند گرفتن سفارش سایت از مشتری و تبدیل آن به یک دیپلوی مستقل و آماده‌ی تحویل.

## بخش ۲ — ساختار فنی پروژه (Technical Project Structure)

### ۲.۱ نگاشت پکیج → معماری

| پکیج | نوع سایت | نیاز به دیتابیس؟ | نیاز به پنل ادمین؟ |
|---|---|---|---|
| Basic | HTML استاتیک (بدون بک‌اند) | خیر | خیر |
| Professional | `pixflow-server` کامل (Node.js + Express + lowdb) | بله | بله |
| Growth | `pixflow-server` + ماژول‌های اضافه (فروشگاه/CRM/آنالیتیکس/اتوماسیون) | بله | بله |

### ۲.۲ نگاشت پکیج → هاست

| پکیج | سرویس پیشنهادی | هزینه‌ی تقریبی ماهانه |
|---|---|---|
| Basic | Render Static Site یا Cloudflare Pages | رایگان تا خیلی کم |
| Professional | Render Web Service (Starter) + Persistent Disk | ~۵-۷ دلار |
| Growth | Render Web Service (پلن قوی‌تر) + Persistent Disk | ~۱۰+ دلار |

### ۲.۳ اصل ایزوله‌سازی (غیرقابل‌مذاکره)
هر سفارش:
- ریپوی گیت‌هاب مستقل خودش را دارد
- سرویس Render مستقل خودش را دارد (نه سرویس مشترک)
- دیتابیس فایلی (`data/db.json`) و Volume مستقل خودش را دارد
- متغیرهای محیطی (`.env`) مستقل خودش را دارد — `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `SESSION_SECRET` همه یکتا برای هر مشتری تولید می‌شوند
- هیچ داده یا اطلاعاتی بین سفارش‌ها به اشتراک گذاشته نمی‌شود

### ۲.۴ مراحل کاری من (Workflow) به ازای هر سفارش

1. **دریافت بریف** — تکمیل فرم بخش ۱ توسط شما
2. **تحلیل و برندینگ** — استخراج پالت رنگی از لوگو (یا پیشنهاد پالت متناسب با صنعت)، انتخاب جفت فونت
3. **محتوانویسی** — تولید متن صفحات (هوم/اباوت/کانتکت/سرویس‌ها...) بر اساس اطلاعات خام مشتری
4. **ساخت پروژه** — کپی ایزوله از کدبیس پایه، تنظیم برای پکیج انتخابی، تزریق محتوا و برندینگ
5. **دیپلوی** — ساخت سرویس مستقل روی Render (از طریق کانکتور متصل) + تنظیم env variables
6. **تحویل** — لینک پیش‌نمایش زنده + راهنمای اتصال دامنه (رکوردهای DNS) + اطلاعات ورود پنل ادمین (برای پکیج Professional/Growth)

### ۲.۵ چک‌لیست تحویل نهایی
- [ ] سایت روی URL موقت Render کاملاً کار می‌کند
- [ ] فرم تماس تست شده و پیام‌ها به صندوق لید می‌رسند
- [ ] برندینگ (رنگ/فونت) با هویت مشتری هم‌خوانی دارد
- [ ] موبایل‌فرست و ریسپانسیو تست شده
- [ ] راهنمای DNS برای اتصال دامنه‌ی نهایی مشتری آماده است
- [ ] (پکیج Professional+) اطلاعات ورود پنل ادمین به مشتری تحویل داده شده
- [ ] `ADMIN_PASSWORD` از Environment Variables حذف شده (طبق نکته‌ی امنیتی README)
